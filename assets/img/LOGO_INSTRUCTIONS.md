# Logo Placement Instructions

## 📍 Where to Place Your Logo

Place the Connect Community logo image in this location:
```
assets/img/logo.png
```

## 📏 Recommended Specifications

- **Format**: PNG with transparent background (preferred) or JPG
- **Height**: 200-300px recommended
- **Width**: Auto (maintains aspect ratio)
- **File size**: Keep under 200KB for optimal loading speed
- **Color mode**: RGB

## 🎨 Logo Guidelines

Based on the Connect Community branding:
- The logo features a globe design with "connect community" text
- Primary colors: Blue (#0066b3) and Orange (#ff6b35)
- The logo appears in the PowerPoint presentation as image 7

## 🔄 Alternative Options

If you don't have the logo file yet, you can:

1. **Extract from PowerPoint**:
   - Open the PowerPoint file
   - Right-click on the logo (image 7)
   - Select "Save as Picture"
   - Save as PNG format
   - Place in `assets/img/logo.png`

2. **Use Temporary Placeholder**:
   - The website will still work without the logo
   - The text "Connect Community" will display
   - Replace with actual logo when available

## 📂 Other Images

You can also add other images to enhance the website:

```
assets/img/
├── logo.png              # Main logo (REQUIRED)
├── about-image.jpg       # About page hero image (optional)
├── hero-bg.jpg          # Hero section background (optional)
└── events/              # Event images (optional)
```

## 🖼️ Additional Image Guidelines

For best results:
- **Hero images**: 1920x1080px
- **Content images**: 800-1200px wide
- **Format**: JPG for photos, PNG for graphics
- **Optimization**: Use compressed images for web
